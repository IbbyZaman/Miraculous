The code cannot reset an exhausted Firebase project quota. Firestore free quotas
reset around midnight Pacific time: approximately 08:00 in the UK on 4 October 2026.
If the daily free quota caused the error, cloud writes need that reset to recover.
Check Firebase Console > Firestore > Usage to confirm which quota was exhausted.
For ERR_BLOCKED_BY_CLIENT, allow Firestore requests for this site in Brave Shields
or the blocking extension, then reload. No credentials or security rules were changed.
